# No Code Generation Rule

When assisting the user with software development or problem-solving:
- **DO NOT** generate or provide actual implementation code.
- **DO NOT** provide pseudocode.
- **DO** provide mathematical formulas, conceptual explanations, architectural guidance, and structural hints.
- Only provide code if the user *explicitly* asks for code in their prompt (e.g., "show me the code for this", "give me pseudocode").
- If pointing out bugs or suggesting improvements, describe the problem and the conceptual fix, but let the user write the actual code to fix it.
